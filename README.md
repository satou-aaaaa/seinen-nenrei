# 18歳でできる？（seinen-nenrei）

成年年齢が18歳になって変わったこと・変わらないことを当てる1日5問の学習ゲーム。架空の人の年齢としたいことを見て「ひとりでできる・親の同意が要る・20歳まで待つ」を選び、正解したらどの決まり（契約・資格とパスポート・結婚と養子・お酒たばこと公営競技）かも選ぶ。未成年者取消権・親権・養育費など、しくみの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/seinen-nenrei/>

- 中身は政府広報オンライン「18歳から“大人”に！成年年齢引下げで変わること、変わらないこと。」<https://www.gov-online.go.jp/useful/article/201808/2.html> に書いてあることだけです。
- 出てくる人はすべて架空で、問題の場面は練習のための例です。
- このゲームは法律の助言ではありません。契約で困ったときは、消費者ホットライン「188（いやや）」に相談できます。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
